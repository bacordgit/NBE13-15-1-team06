   - 카테고리 상세 조회
   - 카테고리 등록
   - 카테고리 수정
   - 카테고리 삭제
   - 전체 메뉴 목록 조회
   - 메뉴 상세 조회
   - 메뉴 등록
   - 메뉴 일반 수정
   - 메뉴 삭제
   - 주문 접수
   - 이메일별 주문
   - 주문 상세
   - 배송 묶음
   - 카테고리별 메뉴
   - 주문 취소
   - 접수일별 주문 통계
   - 접수일별 메뉴 통계
